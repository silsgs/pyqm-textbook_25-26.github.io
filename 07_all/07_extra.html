Hackathon session#

Short guidelines#

Description#

Today you will be working on a specific challenge related to quantum physics or quantum computing. In groups, your task is to develop a solution using the concepts and tools you’ve learned throughout the course.

We will be using AI copilots to assist you in coding and problem-solving. The focus will be on collaboration, creativity, and critical thinking.

The final part of the session will involve a short presentation (15’), where each group will share their approach, solution, and reflections on the use of AI tools in their process.

Objectives#

  1. Understand the problem statement and requirements.

  2. Collaborate with your team to brainstorm ideas and approaches.

  3. Develop a solution using Python or Mathematica. You can utilize AI copilots to assist in coding and problem-solving.

  4. Prepare a presentation to share your findings and reflect on the use of AI copilots in your process.

Resources you can use#

  • Access to AI copilots for coding assistance. Some examples include GenAI, ChatGPT, or other similar tools.

  • Documentation and resources from previous weeks.

  • Collaboration tools for team communication.

Short presentation outline (15’)#

  1. Background:

    • What was the question?

    • How did you approach it?

  2. Solution development and implementation

  3. Implementation (mathematical and coding)

  4. Critical reflection on the use of AI copilots. Eg:

    • Which AI tool/s did you use?

Problem 1#

Problem on time evolution of a given many-body hamiltonian:

Consider a one-dimensional chain of spin-1/2 particles with nearest-neighbor interactions described by the Heisenberg Hamiltonian: [ H = J \sum_{i=1}^{N-1} \left( S_i^x S_{i+1}^x + S_i^y S_{i+1}^y + S_i^z S_{i+1}^z \right) ] where ( S_i^{x,y,z} ) are the spin operators for the ( i )-th particle, ( J ) is the coupling constant, and ( N ) is the number of particles in the chain.

Your task is to simulate the time evolution of an initial state ( |\psi(0)\rangle ) under this Hamiltonian using the time-dependent Schrödinger equation: [ i\hbar \frac{d}{dt} |\psi(t)\rangle = H |\psi(t)\rangle ]

Objectives#

  1. Implement the Heisenberg Hamiltonian for a chain of ( N ) spin-1/2 particles.

  2. Choose an initial state ( |\psi(0)\rangle ) (e.g., all spins up).

  3. Use numerical methods to solve the time-dependent Schrödinger equation and compute ( |\psi(t)\rangle ) at various time points.

  4. Analyze the time evolution of observables such as magnetization and correlation functions.

  5. Prepare a presentation summarizing your approach, results, and the role of AI copilots in your problem-solving process.

  6. Discuss any challenges faced and how you overcame them using AI tools.

  7. Reflect on the effectiveness of AI copilots in assisting with coding and problem-solving tasks.

  8. Ensure your code is well-documented and includes comments explaining key steps and decisions.

  9. Validate your results by comparing them with known analytical solutions or benchmarks, if available.

  10. Prepare visualizations (e.g., plots) to illustrate the time evolution of the system and key observables.

Solution 1#

import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import expm

# Define parameters
N = 4  # Number of spins
J = 1.0  # Coupling constant
hbar = 1.0  # Reduced Planck's constant
dt = 0.1  # Time step
t_max = 10.0  # Maximum time
num_steps = int(t_max / dt)
# Define spin operators
Sx = np.array([[0, 1], [1, 0]]) / 2
Sy = np.array([[0, -1j], [1j, 0]]) / 2
Sz = np.array([[1, 0], [0, -1]]) / 2
I = np.eye(2)
# Construct the Heisenberg Hamiltonian
H = np.zeros((2**N, 2**N), dtype=complex)
for i in range(N - 1):
    Si_x = np.kron(np.kron(np.eye(2**i), Sx), np.eye(2**(N - i - 1)))
    Si_y = np.kron(np.kron(np.eye(2**i), Sy), np.eye(2**(N - i - 1)))
    Si_z = np.kron(np.kron(np.eye(2**i), Sz), np.eye(2**(N - i - 1)))
    Si1_x = np.kron(np.kron(np.eye(2**(i + 1)), Sx), np.eye(2**(N - i - 2)))
    Si1_y = np.kron(np.kron(np.eye(2**(i + 1)), Sy), np.eye(2**(N - i - 2)))
    Si1_z = np.kron(np.kron(np.eye(2**(i + 1)), Sz), np.eye(2**(N - i - 2)))
    H += J * (np.dot(Si_x, Si1_x) + np.dot(Si_y, Si1_y) + np.dot(Si_z, Si1_z))
# Initial state: all spins up
psi_0 = np.zeros((2**N, 1), dtype=complex)
psi_0[0] = 1.0
# Time evolution
times = np.linspace(0, t_max, num_steps)
magnetizations = []
for t in times:
    U = expm(-1j * H * t / hbar)  # Time evolution operator
    psi_t = np.dot(U, psi_0)  # Evolve the state
    # Calculate magnetization
    Mz = 0
    for i in range(N):
        Si_z = np.kron(np.kron(np.eye(2**i), Sz), np.eye(2**(N - i - 1)))
        Mz += np.vdot(psi_t, np.dot(Si_z, psi_t)).real
    magnetizations.append(Mz / N)
# Plot results
plt.plot(times, magnetizations)
plt.xlabel('Time')
plt.ylabel('Average Magnetization <Mz>')
plt.title('Time Evolution of Magnetization in Heisenberg Chain')
plt.grid()
plt.show()

Let the dynamics of a two-level system be described by the Hamiltonian

\[ H = \Gamma(t) \sigma_{3} + \omega \sigma_{1} \]

The goal is to find an optimal driving \(\Gamma(t)\) such that the corresponding time-development operator \(U_{H}(t,0)\) evolves an inittial state \(|\psi_{in}\rangle\) at time \(t=0\) to (a multiple of) a final state \(|\psi_{f}\rangle\) in minimal time \(T = T_{min}\), i.e.

\[ U_{H}(T_{min},0) |\psi_{in}\rangle = \lambda |\psi_{f}\rangle \]

Where, \(|\psi_{in}\rangle\) and \(|\psi_{f}\rangle\), are:

\[\begin{split} |\psi_{in}\rangle = \left(\begin{array}{c} \cos \theta_{in}/2 \\ \sin \theta_{in}/2 \end{array}\right) , \quad |\psi_{f}\rangle = \left(\begin{array}{c} \sin \theta_{f}/2 \\ \cos \theta_{f}/2 \end{array}\right) \end{split}\]
\[ \theta_{in} = \pi/2 + \alpha, \quad \theta_{f} = \pi/2 - \alpha, \quad \alpha = 0 \]

4.1 Coherent states#

A coherent state of a one-dimensional simple harmonic oscillator is defined to be an eigenstate of the non-Hermitian (i.e. \(a \neq a^{\dagger}\)) annihilation operator \(a\).

\[ a|\alpha\rangle = \lambda |\alpha\rangle \]

where \(\lambda\), because of the non-Hermiticity of \(a\), is a complex number. Coherent states are specific linear combinations of harmonic oscillator eigenfunction that produce Gaussian wave packets that do not spread in time. Moreover, if the uncertainties in position and time are equal, then the resulting wave packet would be as close a representation of a classical particle as could be obtained whithin the bounds of the uncertainty principle.

  1. Show that a coherent state can also be obtained by appliying the translation (finite displacement) operator:

\[ e^{\alpha a^\dagger - \alpha^{*} a} | 0 \rangle = | \alpha \rangle \]

Solution:

import numpy as np
from scipy.linalg import expm

# Define the annihilation and creation operators
a = np.array([[0, 1], [0, 0]])
adag = np.array([[0, 0], [1, 0]])

# Define the ground state |0>
psi_0 = np.array([[1], [0]])

# Define the translation operator
alpha = 1.0 + 1.0j
T = expm(alpha * adag - np.conj(alpha) * a)

# Apply the translation operator to the ground state
psi_alpha = np.dot(T, psi_0)
print("Coherent state |alpha>:\n", psi_alpha)

4.2 Spin angular momenta#

Consider two identical spin \(1/2\) fermions, and let \(\chi_{+}(i)\) represent the state of particle \(i\) with spin up, and \(\chi_{-}(i)\) the state of particle \(i\) with spin down. Write down the four possible two-particle spin states, of the system which have definite exchange symmetry.

Show that \(\hat{S}^{2} = \hat{S}_{+} \hat{S}_{-} + \hat{S}_{z}^{2} - \hbar \hat{S}_{z}\), where the spin raising and lowering operators are given by \(\hat{S}_{\pm} = \hat{S}_{x} \pm i \hat{S}_{y}\). Using this result, or otherwise, show that the four states of definite exchange symmetry are eigenstates of \(\hat{S}^{2}\) and find the corresponding eigenvalues and hence the total spin quantum number for each state.

At a given moment, the system is in the state $\( \psi = \sqrt{\frac{2}{3}} \chi_{+}(1) \chi_{-}(2) + \sqrt{\frac{1}{3}} \chi_{-}(1) \chi_{+}(2) . \)$
